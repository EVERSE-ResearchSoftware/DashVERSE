Run an assessment

Use resqui to assess a repository, then submit the result to DashVERSE. Generate an API token above first; the recipes below assume it's in the DASHVERSE_TOKEN environment variable.

This instance's API URL: {{ dashverse_api_url }} — use it as DASHVERSE_URL below.

  1. Install resqui from the QualityPipelines repository (not on PyPI yet):

    pip install "git+https://github.com/EVERSE-ResearchSoftware/QualityPipelines.git"

  2. Export your DashVERSE token, the API URL of this instance, and a personal GitHub API token (any token with the public_repo scope is fine):

    export DASHVERSE_TOKEN="paste-your-dashverse-api-token"
export DASHVERSE_URL="{{ dashverse_api_url }}"
export RESQUI_GITHUB_TOKEN="paste-your-github-token"

  3. Run resqui against a remote repository (or omit -u to assess the current directory). The -d flag publishes the result directly to DashVERSE:

    resqui \
    -u https://github.com/EVERSE-ResearchSoftware/QualityPipelines.git \
    -c configurations/basic.json \
    -v \
    -t $RESQUI_GITHUB_TOKEN \
    -d $DASHVERSE_TOKEN

Refresh the Assessments dashboard to see the new assessment.

Uses the official resqui-github-action. The action assesses the repo and uploads the result when a dashverse_token is provided.

  1. Add a DASHVERSE_TOKEN secret at Settings › Secrets and variables › Actions with the API token you generated above.

  2. Drop this workflow at .github/workflows/dashverse.yml:

    {% raw %}
    name: DashVERSE assessment

on:
  push:
    branches: [main]
  workflow_dispatch:

jobs:
  assess:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Run resqui
        uses: EVERSE-ResearchSoftware/resqui-github-action@main
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          dashverse_token: ${{ secrets.DASHVERSE_TOKEN }}
    {% endraw %}

  3. Push to main (or trigger the workflow manually). Each run assesses the repository and uploads one assessment to DashVERSE.
