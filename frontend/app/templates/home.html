The EVERSE quality model

Dimensions

Broad quality concerns such as FAIRness, Maintainability, Security and Functional suitability. They group related indicators together.

Browse all dimensions →

Indicators

Concrete, measurable criteria that automated tools can check — "software has license", "software has citation", "tests pass". Each indicator belongs to one or more dimensions.

Browse all indicators →

Outcomes

Each check resolves to Pass, Fail or Not applicable. The dashboards aggregate these categorical outcomes — no opaque "quality score", no compliance threshold.

Read the Concepts page →

How DashVERSE works

  1. Run a quality assessment with QualityPipelines.
  2. Submit the result via the DashVERSE API using a personal token.
  3. Your software's outcomes land on the dashboards and feed the portfolio-wide numbers on the Overview.
